# 每日教材新增指南（Day 51–90）

排程任務每次依這份指南新增下一天教材。人工新增時也照這份做。

## 每次要做的事

1. 找出下一天：`dist/data/curriculum.json` 中第一個 `"available": false` 的 day（若已有尚未合併的教材 PR，則從該 PR 分支上的下一天接續）。
2. 讀前兩天的 `day-N.json`，確認格式、難度、複習銜接，以及前一天 `nextDay` 預告的主題。
3. 參考下方大綱撰寫 `dist/data/day-N.json`。大綱是方向，可依前一天 `nextDay` 微調標題。
4. 更新 `curriculum.json` 該天：`"available": true`、`"title"` 與教材 `title` 完全相同。
5. 執行 `python3 scripts/validate_day.py N`，必須顯示 OK。
6. commit 訊息沿用既有風格：`add day N`。

## 格式（與 Day 45–50 完全一致）

頂層欄位依序：`schemaVersion: "1.0"`、`day`、`title`、`courseTitle: "TOEIC 金色證書 90 天訓練"`、
`targetScore: 860`、`minutes: 115`、`durationMinutes: {min:110,max:120}`、`level: "860-900+ baseline"`、
`source: "Claude 依課程大綱產生的 Day N 網站 JSON"`、`sections`、`vocabulary`、`quizzes`、`keyTakeaway`、`nextDay`。

`sections` 固定 12 個，每個只有 `title` 與 `markdown`：

| # | title 格式 | 內容 |
|---|---|---|
| 1 | `Day N 學習概覽` | 5 點目標 + `建議訓練時間：**115 分鐘**。` |
| 2 | `① 今日單字｜30 個` | 單字 \| 中文 \| TOEIC 高頻搭配 表格，與 `vocabulary` 一致 |
| 3 | `② 今日文法｜<主題>` | `主題：**…**`，5 條 `### 規則 n｜…`，每條說明＋`>` 例句 |
| 4–6 | `03/04/05 Listening｜<英文標題>` | `先閱讀題目，再聆聽內容並完成作答。\n\n聽力稿：\n\n> …`（朗讀功能依賴「聽力稿：」） |
| 7 | `⑥ Reading｜<英文標題>` | `限時：**10 分 0 秒**。` + 三篇 `### 文件名` + `>` 內文 + `用途：參考文件` |
| 8 | `⑦ Part 5 仿真題｜15 題` | `限時：**4 分 0 秒**。` |
| 9 | `⑧ Part 6 篇章填空｜4 題` | `限時：**3 分 0 秒**。` + `### 閱讀文章` + 含 [1]–[4] 空格的 `>` 文章 |
| 10 | `⑨ Day N 小考` | `正式限時：**6 分 0 秒**。` |
| 11 | `⑩ 複習與錯題分類` | 回顧前三天、複習重點、錯題標籤 |
| 12 | `⑪ 今日作業` | 6 項作業 |

`vocabulary`：30 筆 `{id, word, meaning, phrase}`，不可與前 3 天重複。

`quizzes` 固定 7 組，每題 `{id, prompt, options:{A,B,C,D}, answer, explanation}`（解析用繁體中文）：
`listening-1`(3)、`listening-2`(4)、`listening-3`(4)、`reading-triple-passage`(8)、`part-5`(15)、`part-6`(4)、`day-N-quiz`(12)。
答案 A–D 要分散，每個字母不超過約三成。

整合日（56、63、70、77、84）與模考日沿用同樣格式，只是主題改為綜合複習、題目跨前幾天主題混合。
